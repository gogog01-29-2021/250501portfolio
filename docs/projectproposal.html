Project Overview

This project demonstrates a sophisticated communication system between autonomous ground vehicles and aerial drones, connected via satellite relay. The system enables seamless data transfer in real-time, allowing for coordinated navigation and mission execution even in remote areas with limited connectivity.

Key Features

  • Low-latency communication between vehicle and drone
  • Satellite data relay for extended operational range
  • Real-time telemetry and mission data synchronization
  • Encrypted and secure data transmission protocols
  • Autonomous coordination in navigation and data gathering

Technologies Used

IoT Satellite Communications Python ROS (Robot Operating System) Computer Vision MQTT Protocol

Project Impact

  • 98.7% Connection Reliability
  • 12ms Average Latency
  • 50km Max Operational Range
  • 256-bit Encryption

Applications
